# Portfólio - Elizabeth Silvano

## 👩‍💻 Sobre

Portfólio profissional desenvolvido para apresentar a experiência, projetos e habilidades de Elizabeth Silvano, Frontend Engineer especializada em Vue.js, React e Angular.

## 🚀 Características

- **Design Moderno e Responsivo**: Interface adaptável para todos os dispositivos
- **Performance Otimizada**: Carregamento rápido e animações suaves
- **SEO Friendly**: Estrutura otimizada para mecanismos de busca
- **Acessibilidade**: Seguindo as melhores práticas de acessibilidade web
- **Animações Interativas**: Experiência visual envolvente com scroll animations
- **Clean Code**: Código organizado e bem documentado

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilos modernos com variáveis CSS, Grid e Flexbox
- **JavaScript (ES6+)**: Interatividade e animações
- **Font Awesome**: Ícones vetoriais
- **Google Fonts**: Tipografia (Poppins e Fira Code)

## 📋 Seções

1. **Home** - Hero section com apresentação e call-to-actions
2. **Sobre** - Resumo profissional, formação e estatísticas

4. **Projetos** - Destaque dos principais projetos desenvolvidos
5. **Habilidades** - Stack técnico e metodologias utilizadas
6. **Contato** - Informações para contato e links sociais

## 🚀 Como Usar

### Visualização Local

1. Clone ou faça download do repositório
2. Navegue até a pasta do portfólio:
   ```bash
   cd portfolio
   ```
3. Abra o arquivo `index.html` em seu navegador ou use um servidor local:
   ```bash
   # Com Python 3
   python -m http.server 8000
   
   # Com Node.js (http-server)
   npx http-server
   
   # Com PHP
   php -S localhost:8000
   ```

### Deploy

O portfólio pode ser facilmente hospedado em:
- **GitHub Pages**
- **Netlify**
- **Vercel**
- **Cloudflare Pages**
- Qualquer servidor web estático

## 🎨 Customização

### Cores
As cores podem ser facilmente customizadas editando as variáveis CSS no início do arquivo `style.css`:

```css
:root {
    --primary-color: #42b983;
    --secondary-color: #35495e;
    --accent-color: #ff6b6b;
    /* ... outras variáveis */
}
```

### Conteúdo
Todo o conteúdo pode ser editado diretamente no arquivo `index.html`.

### Animações
As animações e interações podem ser ajustadas no arquivo `js/main.js`.
