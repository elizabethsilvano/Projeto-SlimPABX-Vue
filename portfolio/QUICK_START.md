## 🚀 Visualização Local (3 Passos)

### Opção 1: Abrir Diretamente
```bash
# 1. Abra o arquivo no navegador
open portfolio/index.html

# ou no Windows
start portfolio/index.html

# ou no Linux
xdg-open portfolio/index.html
```

### Opção 2: Servidor Python
```bash
# 1. Entre na pasta
cd portfolio

# 2. Inicie o servidor
python3 -m http.server 8000

# 3. Abra no navegador
# http://localhost:8000
```

### Opção 3: Servidor Node.js
```bash
# 1. Entre na pasta
cd portfolio

# 2. Instale http-server (se não tiver)
npm install -g http-server

# 3. Inicie o servidor
http-server

# 4. Abra no navegador
# http://localhost:8080
```

## ✏️ Personalização Rápida

### 1. Mudar Nome e Email
Edite `index.html`, linha ~31:
```html
<h1 class="hero-title">Seu Nome</h1>
```

Linha ~49:
```html
<a href="mailto:seu-email@email.com">
```

### 2. Mudar Cores
Edite `css/style.css`, linha ~6:
```css
--primary-color: #42b983;  /* Sua cor aqui */
```

### 3. Adicionar Foto
Substitua no `index.html`, linha ~61:
```html
<img src="images/sua-foto.jpg" alt="Seu Nome">
```

## 🚀 Deploy Rápido

### GitHub Pages (Mais Fácil)
1. Vá em: `Settings` > `Pages`
2. Source: `Deploy from branch`
3. Branch: `genspark_ai_developer`
4. Folder: `/portfolio`
5. Save! 🎉

### Netlify (Mais Rápido)
1. Acesse: https://app.netlify.com
2. "Add new site" > "Import from GitHub"
3. Selecione o repositório
4. Base directory: `portfolio`
5. Deploy! 🚀
